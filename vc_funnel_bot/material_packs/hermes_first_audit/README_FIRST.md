# Hermes First Audit Pack

Этот пакет превращает видео Андрея про Hermes в измеримый маршрут:

`видео → два вопроса → узкое звено → готовый артефакт → канал или контекст → команда`

## Что внутри

### Материалы для пользователя
- `01_Komu_predlozhit_Hermes_audit.pdf` — выбрать первые компании.
- `02_Offer_dlya_biznesa.pdf` — сформировать безопасный оффер.
- `03_Hermes_Audit_Kit.pdf` — провести аудит.
- `04_Ot_otcheta_k_sdelke_i_RKO.pdf` — показать результат и перейти к пилоту / РКО при реальной потребности.
- `Hermes_Audit_Prompt.pdf` — готовый промпт.
- `Hermes_Audit_Workbook.xlsx` — лид-лист, рабочая таблица, сводка и сценарий созвона.
- `Hermes_Outreach_Templates.pdf` — сообщения бизнесу.
- `Hermes_Result_Presentation_Script.pdf` — сценарий презентации.

### Для Codex / разработчика
- `bot_flow_spec.json` — точные тексты, callbacks и bundles.
- `CODEX_IMPLEMENT_HERMES_ROUTER.md` — полный промпт на реализацию.
- `material_upload_manifest.csv` — material keys и файлы.

## CTA Андрея в конце видео

> Я показал, как Hermes устанавливается и анализирует переписки. Но сам инструмент ещё не даёт результат, если непонятно, кому его предложить, что проверить и как показать найденную проблему. Зайдите в Telegram-бота, ответьте на два вопроса — он определит ваше узкое звено и выдаст готовый следующий шаг: список компаний, оффер, комплект аудита или сценарий перехода к сделке.

## Порядок запуска

1. Передать `CODEX_IMPLEMENT_HERMES_ROUTER.md` Codex.
2. После реализации загрузить материалы через `/material_add` по `material_upload_manifest.csv`.
3. Записать и загрузить три видео: Windows, macOS, подключение модели.
4. Проверить `/preview am_hermes_video_route`.
5. Пройти все пять веток через `/reset_vc`.
6. Отправить контрольную заявку и проверить карточку у Игоря.
7. Поставить deep link в CTA видео:
   `https://t.me/viberko_bot?start=am_hermes_video_route`
8. После первых 30–50 стартов сравнить: start → question 1 → question 2 → bundle delivered → channel/apply → call.

## Критерий первой итерации

Пользователь максимум за два ответа получает один конкретный следующий шаг и хотя бы один рабочий артефакт. Продажники получают уведомление только после явного текстового контекста.
