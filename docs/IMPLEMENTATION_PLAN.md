## 0. Главный вывод разведки (читать первым)

**Бóльшая часть уже построена.** Это меняет характер плана: это не greenfield-сборка, а **доведение + примирение с правилами CLAUDE.md**.

| Область | Реальное состояние |
|---|---|
| **Лендинг** | Все 14 секций из брифа существуют и подключены в `page.tsx`. Шрифты мигрированы (Geologica + IBM Plex, кириллица). Framer Motion в коде нет. Анимации CSS + `MotionBudgetController`, gated по motion-mode, reduced-motion и mobile blur учтены. |
| **Tier 1 — RKO Lead Command Center** | **Полностью функционален и собирается чисто.** 4 экрана (`/demo/rko`, `/chat`, `/dashboard`, `/traffic`) + `/script` + `/playground`. Скоринг A–F по модели из брифа, mock-AI (без внешнего LLM), seed 100 лидов, dedup, traffic radar, API-роуты, live-карточка в дашборде через polling. |
| **Tier 2 — моки Хаслеры / Челы с каналами** | **Не существует.** Есть только `demo/rko`. На лендинге есть визуалы (Cases, BentoBuilds), но отдельных демо-моков под сегменты нет. |

**Главные расхождения с CLAUDE.md (это и есть основная работа):**

1. **Дизайн — прямое нарушение.** Текущая палитра = navy + cyan (`#22d3ee`, `cyan-200` ×90) + violet (`violet-300`) + glassmorphism. CLAUDE.md это явно запрещает как «AI-slop» и требует **ОДИН тёмный фон + ОДИН резкий акцент**, направление «операционный intelligence-терминал».
2. **Токены хардкодом.** ~250+ хардкод-значений цветов (hex/rgba/tailwind-классы) по компонентам. CLAUDE.md: «CSS-переменные на всё, ничего хардкодом, токены в `DESIGN.md`». **`DESIGN.md` отсутствует.**
3. **Hero не «живой».** CLAUDE.md хочет в hero «живой проход лида pipeline → score → CRM, CSS-driven». Сейчас `HeroWowLayer` — статичный мокап (parallax-карточки + типографический терминал), без живого прохода лида.
4. **Storage демо.** CLAUDE.md говорит «local-first (`localStorage`)». Реально демо хранит в серверном `.rko-data/db.json` + API + polling 5с. Работает и даёт cross-window wow, но это расхождение → решение ниже.
5. **Orphan-зависимость.** `framer-motion@^12.40.0` в `package.json`, импортов в `src/` нет. Под удаление.
6. **Telegram URL.** `TELEGRAM_URL = https://t.me/lv3rson` с TODO «проверить `lv3rson` vs `Iv3rson`». Блокер DoD.

## 2. Приоритеты и cut-lines к 21 июня

Легенда: **MUST** = без этого не гоним трафик · **SHOULD** = сильно желательно (мандат CLAUDE.md) · **CUT** = режем первым при дефиците времени.

```
КРИТИЧЕСКИЙ ПУТЬ К ЗАПУСКУ (MUST):
  P0 гигиена → P2.1 QA демо-флоу → P5 DoD-гейт перед трафиком

ЖЕЛАТЕЛЬНО (SHOULD): P1 дизайн-фундамент (DESIGN.md + токены + один акцент) → P2.2 стиль демо

РЕЖЕМ ПРИ ДЕФИЦИТЕ (CUT, в порядке отрезания):
  1) P4.2 второй Tier-2 мок (Челы с каналами)
  2) P3 hero live-moment (оставляем текущий статичный wow)
  3) P4.1 первый Tier-2 мок (опираемся на существующие Cases-визуалы)
  4) P1.3 глубокий рефактор цветов (оставляем «light»-минимум: только один акцент в hero/CTA)
```

## 3. Definition of Done (применяется к КАЖДОЙ задаче)

Из `CLAUDE.md`. Задача не закрыта, пока не выполнено всё применимое:

- [ ] `pnpm lint` проходит без ошибок.
- [ ] `pnpm build` (`next build`) проходит без ошибок.
- [ ] Нет console errors в prod-smoke на `/`, `/demo/rko/dashboard`, `/demo/rko/chat`, `/demo/rko/traffic` (+ новые роуты задачи).
- [ ] Нет горизонтального оверфлоу на мобильном вьюпорте (≤390px).
- [ ] Анимации не активны на мобиле / coarse pointer / при `prefers-reduced-motion`.
- [ ] Нет `REPLACE_ME` в UI; CTA ведёт в правильный Telegram.
- [ ] Изменены только нужные файлы (minimal impact); никаких новых либ без причины.

DoD-теги в задачах ниже отмечают, что **специфично** для задачи сверх этого базового списка.

### PHASE 1 — Дизайн-фундамент: DESIGN.md + токены + один акцент (SHOULD) · зависит от D1

> Это мандат CLAUDE.md и фундамент для P2.2/P3/P4 (чтобы новый код шёл уже на токенах). «Light»-объём по D1.

#### T1.1 — Создать `DESIGN.md` (источник истины) · SHOULD
- **Что:** Зафиксировать ОДНО направление: операционный intelligence-терминал. ОДИН доминантный тёмный фон + ОДИН резкий акцент (выбрать: оставить cyan как единственный акцент ИЛИ заменить). Шкала типографики (Geologica/IBM Plex уже стоят), spacing, радиусы, философия движения (CSS-only, gated). Разрешить/запретить glass.
- **Файлы:** `DESIGN.md` (корень), ссылка из `CLAUDE.md` и `AGENTS.md`.
- **DoD-специфика:** документ; решён конфликт `AGENTS.md` ↔ `CLAUDE.md` (D1). Кода нет.
- **Зависимости:** D1.

#### T1.2 — Завести CSS-переменные на токены · SHOULD
- **Что:** В `globals.css :root` объявить переменные на цвета (bg-уровни, один акцент, текст, бордеры, риск-семантика A–F), spacing-шкалу, радиусы. Сопоставить с `@theme inline`.
- **Файлы:** `src/app/globals.css`.
- **DoD-специфика:** переменные определены; визуально ничего не сломано (значения = текущим, пока без схлопывания палитры).

#### T1.3 — Рефактор хардкод-цветов → токены, схлопнуть рейнбоу до одного акцента · SHOULD (часть — CUT)
