# CLAUDE.md — VibeCamp / RKO AI Build Sprint

Контекст проекта и правила разработки для Claude Code. Читается автоматически. Полный продуктовый контекст — в `VibeCamp_RKO_master_context_pack`; Этот файл — про КАК строить.

## Проект

- Next.js (App Router) лендинг `atscollab.tech/landing-rko` + demo `/demo/rko/*` (RKO Lead Command Center).
- Цель: лендинг + одно рабочее hero-демо к запуску 21 июня. Аудитория — РКО/Telegram-трафик из канала Андрея.
- Demo-данные local-first (`localStorage`), mock AI mode без внешнего LLM. Без реальных банков, без PII, без обещаний approve/дохода.

## Принцип сборки демо (тируем, не плодим)

- **Tier 1 — одно рабочее hero-демо:** RKO Lead Command Center. Полный flow: заявка → AI-квалификация → score/класс A–F → карточка CRM → summary менеджеру → Traffic Quality Radar. Его доводим до чистого прокликиваемого состояния.
- **Tier 2 — визуальные демо-моки под другие сегменты** (Хаслеры: AI-агенты для процессов; Челы с каналами: трафик/контент). Высокий визуальный лоск, БЕЗ полного бэкенда. Это демонстрация, не продакшн. Не строить под каждый сегмент отдельное рабочее приложение.

## Дизайн-направление

- Коммитим ОДНО направление: операционный intelligence-терминал, не generic AI-SaaS.
- ОДИН доминантный тёмный фон + ОДИН резкий акцент. НЕ navy+violet+cyan glassmorphism-рейнбоу (это AI-slop).
- Характерный дисплейный шрифт с поддержкой кириллицы + чистый body. Запрещены Inter, Roboto, Arial, Space Grotesk.
- CSS-переменные на все цвета/шрифты/отступы/радиусы. Ничего хардкодом. (Токены держать в `DESIGN.md` — отдельным файлом, на него ссылаться.)
- Промптить эстетическим направлением (назначение, тон, семья шрифта, цветовая семья, философия движения), а не пиксельными значениями.

## Анимации и performance (НЕ регрессировать — это уже было выстрадано)

- **Framer Motion не возвращать.** Только CSS transitions/animations.
- Тяжёлые секции — server/static components; client только где реально нужен интерактив.
- Далёким секциям — `content-visibility: auto`.
- Один оркестрированный hero-загруз (staggered CSS reveals) важнее множества микроанимаций.
- Hero-момент: живой проход лида pipeline → score → CRM, CSS-driven.
- Все декоративные анимации gated: `@media (hover:hover) and (pointer:fine)`, уважать `prefers-reduced-motion`, на мобиле/coarse pointer — выключать.
- На мобиле снижать blur/backdrop-filter.
- Таблицы/строки — мемоизация; пагинация (≤40 строк на страницу); статистика одним проходом; низкоприоритетные апдейты через `startTransition`.
- Нет двойного re-render после записи в store.

## Definition of Done (каждый ПР)

- `lint` и `next build` проходят, без ошибок.
- Нет console errors в production smoke (`/`, `/demo/rko/dashboard`, `/demo/rko/chat`, `/demo/rko/traffic`).
- Нет горизонтального оверфлоу на мобильном вьюпорте.
- Первый экран понятен за 5 секунд; CTA ведёт в правильный Telegram; нет `REPLACE_ME` в UI.
- Анимации не активны на мобиле/при reduced-motion.

## Стоп-лист

- Не пересоздавать лендинг с нуля — дорабатывать существующий.
- Не возвращать Framer Motion и тяжёлые анимации на мобиле.
- Не строить отдельные рабочие приложения под каждый сегмент (только Tier-2 моки).
- Не использовать реальные имена банков, телефоны, PII; не обещать гарантированный доход/approve/обход проверок.
- Не открывать новый стек/библиотеку без причины, привязанной к задаче.
