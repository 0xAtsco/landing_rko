# VibeCamp — build brief для Claude Code

Короткий заточенный бриф под запуск 21 июня. Полный контекст продукта/оффера/ЦА — в `VibeCamp_RKO_master_context_pack`. Правила сборки/дизайна/perf — в `CLAUDE.md`. Этот файл задаёт ФОКУС и стоп-лист, чтобы не распылиться.

---

## Фокус запуска

- **Три сегмента, все из канала Андрея** (кастдевы вытащили их из канала, значит они в аудитории запуска):
  - **РКО Middle** — основной объём (до 150к на РКО, без команды). Аудитория Андрея по умолчанию.
  - **Челы с каналами** — продюсеры / личные каналы с прогревом.
  - **Хаслеры** — команда, несколько источников дохода, ~500к, AI-агенты для процессов.
- Сегмент-матченное демо конвертит лучше: человек видит штуку под СВОЮ ситуацию. Андрей совмещает все три → на нём показываем всю витрину.
- **Но тируем демо, не плодим четыре полных приложения** (см. ниже).

## Что строим (тиринг)

- **Tier 1 — одно рабочее hero-демо:** RKO Lead Command Center (уже в репо). Полный flow: заявка → AI-квалификация → score/класс A–F → карточка CRM → summary менеджеру → Traffic Quality Radar. Доводим до чистого прокликиваемого состояния. Это то, что вживую показываем на эфире с вау.
- **Tier 2 — визуальные демо-моки под другие сегменты:** Хаслеры (AI-агенты для процессов), Челы с каналами (трафик/контент). Высокий визуальный лоск, БЕЗ полного бэкенда. Демонстрация, не продакшн.
- **Лендинг:** витрина «что можно собрать» под все три сегмента на примере Андрея. Hero-демо рабочее, остальное — моки.

## Definition of Done перед трафиком

Лендинг быстрый на мобиле; первый экран понятен за 5 сек; CTA в правильный Telegram; нет REPLACE_ME; есть demo-case visuals; FAQ заполнен; блок «кому подходит / не подходит» и «после заявки»; один живой demo-flow; нет опасных обещаний (доход / approve / обход проверок).

## Стоп-лист (что остаётся в силе)

- Не делать 3–4 полноценных рабочих приложения. Tier 2 — это моки, не бэкенды.
- Не путать витрину/демо (показать что можно) со scope продукта спринта: участник делает ОДИН артефакт под СВОЮ задачу.
- Не открывать новый холодный канал привлечения (ГТ / Удмурт / вайбкодерские чаты) до запуска. Валидируем тёплый канал Андрея.
- Не запускать проверку спроса заново через интервью. Спрос уже есть (диагностика Андрея: 24 лида, 17 РКО). Валидация = продажа: заявки → созвоны → депозиты.
