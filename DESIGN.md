# DESIGN.md — VibeCamp / RKO

Источник истины по визуальному языку. Все цвета/радиусы — через CSS-переменные (`globals.css`). Ничего хардкодом в компонентах.

## Направление

**Операционный intelligence-терминal**, не generic AI-SaaS. Тёмный «пультовый» фон, один резкий сигнальный акцент, моноширинные акценты для данных. Спокойно, плотно, по делу — как командный центр обработки заявок.

## Правило одного акцента

ОДИН доминантный тёмный фон + ОДИН резкий акцент. **Никакого рейнбоу** (navy+cyan+violet glassmorphism — это AI-slop, запрещено).

Акцент сейчас: **signal amber `#f59e0b`**. Он задан ОДНИМ токеном — свап тривиален:

```css
/* globals.css :root — поменять одну строку, чтобы перекрасить весь сайт */
--signal-rgb: 245 158 11;   /* signal amber */
```

Менять только `--signal-rgb` (+ при желании `--signal-bright`/`--signal-strong`). Компоненты на токены не завязаны на конкретный цвет.

## Токены

### Акцент (единственный)
| Токен | Значение | Назначение | Tailwind-утилита |
|---|---|---|---|
| `--signal` | `rgb(var(--signal-rgb))` = `#f59e0b` | основной акцент: CTA, активные бордеры, ключевой текст, glow | `text-signal` `bg-signal/10` `border-signal/30` |
| `--signal-bright` | `#fcd34d` (amber-300) | светлые хайлайты, акцентный текст на тёмном | `text-signal-bright` |
| `--signal-strong` | `#d97706` (amber-600) | глубже/hover, насыщенные состояния | `bg-signal-strong` |

`rgb(var(--signal-rgb) / <a>)` — для произвольной альфы в CSS. В утилитах — модификатор `/NN`.

### Поверхности (один тёмный фон-семейство)
| Токен | Значение | Назначение |
|---|---|---|
| `--surface-base` | `#020817` | базовый фон страницы |
| `--surface-1` | `#04101f` | приподнятые панели |
| `--surface-2` | `#06172e` | карточки/строки |
| `--surface-line` | `rgb(255 255 255 / 0.08)` | хайрлайн-бордеры |

Tailwind: `bg-surface-base` `bg-surface-1` `bg-surface-2`.

### Нейтрали
`slate-*`, `white`, `black` остаются как структурные нейтрали (текст, приглушённые подписи, разделители). Это НЕ акцент — их не трогаем при свапе.

### Семантика классов лида A–F (для демо, применяется в T2.2)
A — успех/зелёный, B — акцент, C — нейтраль, D — приглушённый, F — destructive/красный. Держать отдельными семантическими токенами, не путать с brand-акцентом.

## Типографика
- Заголовки: **Geologica** (`--font-heading`), кириллица. Дисплейный, технический характер.
- Body/UI: **IBM Plex Sans** (`--font-sans`).
- Данные/терминал/метрики: **IBM Plex Mono** (`--font-mono`).
- Запрещены: Inter, Roboto, Arial, Space Grotesk.

## Радиусы
Через `--radius: 0.625rem` и шкалу `--radius-sm..4xl` в `@theme`. Не хардкодить `rounded-[Npx]`.

## Spacing
Шкала Tailwind (`p-4`, `gap-6`, …) — это и есть токен-система отступов. Не вводить произвольные `[Npx]` без причины.

## Движение
- Только CSS transitions/animations. **Framer Motion запрещён.**
- Один оркестрированный hero-загруз важнее россыпи микроанимаций.
- Все декоративные анимации gated: `@media (hover:hover) and (pointer:fine)`, уважать `prefers-reduced-motion`, на мобиле/coarse — выключать.
- На мобиле снижать blur/backdrop-filter.

## Glass
Сдержанно. Лёгкий `backdrop-blur` на панелях допустим, но без многослойного «стекла-рейнбоу». На мобиле blur снижается до 6px (см. `globals.css`).
